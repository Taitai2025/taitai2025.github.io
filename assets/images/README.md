# Image placeholders

You can directly replace these files without changing code:

- `avatar.jpg` — cover page avatar
- `profile.jpg` — photo in the About / Resume section
- `favicon.png` — website favicon
- `cover_1.jpg` ~ `cover_6.jpg` — rotating cover backgrounds
- `background.jpg`, `old-paper-texture.jpg`, `scroll-texture.png` — optional background / texture assets

If you add more cover images, also update `assets/js/Functions/Cover.js`.
