## 十项实际通过的 Lean 断言

命名空间为 `RestartProjectedBB`。源文件为 `RestartProjectedBB.lean`，公理输出为 `lean-verification.log`。

| 名称 | 实际核验内容 |
|---|---|
| `positive_dual_forces_trigger` | 任意有限矩阵的非负对偶证书在每个谱节点严格正，且原权重非负、和为 1，推出某个试探时刻的判据严格正 |
| `projection_equality_contradiction` | τ,b,vnormSq>0 与 −τbvnormSq=0 不能同时成立 |
| `strict_two_step_max` | 从 v≤u、w<v、t≤w 推出 max(w,t)<max(u,v) |
| `exact_dual_first` | s=1/2 的两时刻对偶组合等于正文第一个有理数 |
| `exact_dual_second` | s=9/10 的同一组合等于正文第二个有理数 |
| `exact_dual_positive` | 两个有理组合均严格为正 |
| `exact_no_earlier_trigger` | 均分权重前 11 次判据全部严格负 |
| `exact_trigger_twelve` | 均分权重第 12 次判据严格正 |
| `exact_modes_nonzero` | 两个节点在 0≤k≤12 的残差全部非零 |
| `exact_bb_example` | 逐坐标非负截断算例的 v、α、w、范数平方及目标值精确相等式 |

有理残差通过结构递归定义，初值和递推与正文式 (1) 一致，没有把待证的精确数值作为公理。

**这些接口没有形式化全文。** Darboux 渐近、无限序列的正子列、紧性的有限返回、矩阵谱等号结构、一般锥投影与联合连续性没有整体转写成 Lean。特别是 `projection_equality_contradiction` 把谱论和投影论已导出的标量等式作为假设；它不是这些上游事实的机器证明。`strict_two_step_max` 也不建立紧单位截面或统一收缩因子。

`exact_bb_example` 使用有理坐标的 `max(0,x)`，没有独立形式化一般欧氏投影的定义等价性。正定性及初始化谱区间在正文证明，并由 Python 的顺序主子式与 det(H−I)<0 精确复算补充。
