可用席位

同一乐器有两位独立演奏员时，可以添加两个席位。席位编号在项目内保持不变。音域用实音填写，支持 C4、B♭3 或 MIDI 数字。请按乐器型号、定调与演奏员水平调整默认范围。

输出与核对

  • 一个演奏席位承接一个原谱声部。必保留声部先匹配，随后匹配可选声部。匹配代价由作用差异、音域余量、记谱移调和建议复核项组成。
  • MusicXML 草稿只改写通过安全检查的声部。无法分配或需要手工核对的原声部继续出现在总谱里，校勘表记录原因。
  • 简单单声部支持移调乐器所需的调号与写音转换。导出后重新解析，核对所有声部的实音、拍位和时值。复杂移调、调外音重拼、无固定音高打击与兼奏需要手工处理。
  • 草稿保留原谱谱号和组序。排练前请检查谱号、奏法、换气、指法、平衡、音色和翻页。通用 MIDI 音色用于打样。
