# 高校乐团风采

本栏目面向全球高校征集民族乐团资料，目前实际收录 **2 支乐团**：中国科学技术大学学生民族乐团（NMOU）与西北工业大学大学生艺术团民乐队。收录是一份有来源的介绍，不代表机构合作、正式认证或推荐。

## 维护入口

内容源是 `data.json`。页面由 `scripts/orchestra_showcase.py` 的 `build_showcase(api)` 生成；主站生成器在写入站点地图之前调用该函数，继续复用统一页头、页脚及路线登记。独立运行：

```sh
python scripts/build-orchestra-showcase.py --check
python scripts/build-orchestra-showcase.py
node scripts/test-orchestra-showcase.mjs
```

最后一条命令使用项目既有的 `jsdom` 开发依赖。测试不访问网络。

修改内容、样式或脚本后运行主站统一构建与检查。不要直接修改生成的 `index.html`。`showcase.css` 与 `showcase.js` 仅作用于本栏目；生成器按其实际内容生成 SHA-256 版本参数，避免新页面命中旧样式和脚本缓存。

## 多乐团数据约定

- `orchestras` 是目录与独立页面的共同内容源，计数、学校筛选、图片与视频数量以及站点地图路由由实际数据生成。
- `founded` / `foundedLabel`、`englishName`、`nickname` 和 `sources.officialBilibili` 为可选信息。未知的成立日期与官方账号不会输出到搜索引擎结构化数据。
- 原稿型档案使用 `sources.article`，投稿型档案使用 `sources.submission`（资料名称、核对时点、文字出处、照片出处、授权说明）。`sources.references` 可补充带发布日期的公开报道；学校管理机构主页使用 `sources.institution`，不作为乐团账号。
- 每条时间线记录的 `source` 必须能解析到原稿、投稿说明、公开报道或已有 PDF。NMOU 的 `yearbook` / `documents` / `honors` 继续保留页码与指纹约束；其他乐团没有此类材料时不生成空板块。
- 照片需要尺寸、替代文本、图注、日期说明和来源；本地个人主页锚点按真实页面校验，投稿照片的 `#sources` 必须配套投稿授权信息。新增外部来源时，维护者应核对域名并更新 `checked_url` 的允许范围。
- `videos[].year` 表示音乐会标示年份，实际日期差异写在 `note`。只收录核对过的 B 站直接链接，禁止将共享短链追踪参数写进公共数据。
- 邮件入口与下载模板从统一的 `scores/community/config.json` 读取邮箱、微信与 QQ；修改联系人时只改配置并重新构建，不在栏目生成器里另行维护联系方式副本。

## 交互与可访问性

- 全部介绍、图片、视频入口均在静态 HTML 中；目录和音乐会筛选是渐进增强，不依赖另一次网络请求。
- 搜索会保留到当前 URL，可分享或刷新；支持学校别名、英文、全角字符以及多关键词组合。
- 图集不自动播放。触摸或滚动条、前后按钮、编号按钮均可切换；聚焦图片列表后可用左右方向键、Home 和 End。
- 图集识别“减少动态效果”偏好；原图链接、图注、来源入口始终可用，图片加载失败会显示说明。
- 打印时展开完整图集及音乐会档案，不将当前筛选状态误印成完整目录。
- `intake-template.txt` 是本地资料草稿模板；收录入口进入专属 `/scores/orchestras/submit/`，同时提供直接邮件投稿。模板与页面列出维护者已公开且授权使用的邮箱、微信与 QQ；投稿人自行发送，维护者核对后收录，没有模拟在线提交。
