# 高校乐团风采

本栏目面向全球高校征集民族乐团资料，目前实际收录 **1 支乐团**：中国科学技术大学学生民族乐团（NMOU）。收录是一份有来源的介绍，不代表机构合作、正式认证或推荐。

## 维护入口

内容源是 `data.json`。页面由 `scripts/orchestra_showcase.py` 的 `build_showcase(api)` 生成；主站生成器在写入站点地图之前调用该函数，继续复用统一页头、页脚及路线登记。独立运行：

```sh
python scripts/build-orchestra-showcase.py --check
python scripts/build-orchestra-showcase.py
node scripts/test-orchestra-showcase.mjs
```

最后一条命令使用项目既有的 `jsdom` 开发依赖。测试不访问网络。

修改内容、样式或脚本后运行主站统一构建与检查。不要直接修改生成的 `index.html`。`showcase.css` 与 `showcase.js` 仅作用于本栏目。

## 内容与出处

- NMOU 正文依据用户授权的微信公众号介绍原稿整理，原稿编辑为杨书泰；原文链接保存在数据中，发布日期尚未确认。
- 原文的“70 余位正式演奏员”和“23 届专场音乐会”只在来源说明中保留为历史记录，不推算为当前统计。
- 音乐会链接由用户提供。年份按演出记录整理，不擅自填写视频发布日期、时长或节目单。
- 所用照片复用已有 `assets/images/music/` 图片，无新增大二进制副本。六张照片均已逐张查看；图注、日期及来源锚点来自个人主页既有记录。摄影者未逐张确认时不虚构署名。
- 不收集或展示个人 QQ、手机号等私人联络名单；当前活动与招新请读者查看官方公开渠道。

增加一支乐团时，应同时补齐名称、所属高校、所在地、介绍、声部与活动、真实照片及可公开展示的依据、官方链接、资料出处。人数、届数等易变化数据必须注明统计时点。没有资料时保留未收录状态，不建立虚构或占位乐团。

## 交互与可访问性

- 全部介绍、图片、视频入口均在静态 HTML 中；目录和音乐会筛选是渐进增强，不依赖另一次网络请求。
- 搜索会保留到当前 URL，可分享或刷新；支持学校别名、英文、全角字符以及多关键词组合。
- 图集不自动播放。触摸或滚动条、前后按钮、编号按钮均可切换；聚焦图片列表后可用左右方向键、Home 和 End。
- 图集识别“减少动态效果”偏好；原图链接、图注、来源入口始终可用，图片加载失败会显示说明。
- 打印时展开完整图集及音乐会档案，不将当前筛选状态误印成完整目录。
- `intake-template.txt` 是本地资料草稿模板；共建入口仍使用站内已有反馈工具，由访问者核对并发送，没有模拟在线提交。

## 发布核对

静态行为测试涵盖来源与内部锚点、真实收录数量、SEO、搜索与空状态、URL 恢复、年份组合筛选、键盘、滚动边界、减少动效、图片异常和打印展开。视觉验收还应在桌面及窄屏检查照片裁切、标题换行、图集可见的下一张提示及键盘焦点；同一次构建重复执行应无输出差异。
